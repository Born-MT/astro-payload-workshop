## The flow — idea → shipped

Run each phase in order. Each **gate** must hold before the next phase begins; skip a phase only
when it plainly doesn't apply, and say so.

1. **Plan** — `senior-software-engineer` scopes the task, lists the files to touch, and names
   the risks. Use plan mode (Shift+Tab) for anything non-trivial. *Gate: a written plan you agree with.*
2. **Build** — hand the work to the specialist who owns it:

   | Work | Owner |
   | --- | --- |
   | Node.js / TypeScript services and APIs | `backend-node-engineer` |
   | CI/CD, containers, release automation | `devops-engineer` |
   | React / Next.js / UI — components, state, accessibility | `frontend-engineer` |
   | Anything unowned / cross-cutting | `senior-software-engineer` |

   *Gate: it compiles and the builder ran the project's build/lint/typecheck.*
3. **Code review** — `code-reviewer` on the diff for real bugs, not style. *Gate: no blocking issue.*
4. **Security review** — for changes to auth, input handling, queries, file paths, tokens, crypto,
   or dependencies: `security-reviewer` **and** run `/security-scan`. *Gate: no critical/high finding.*
5. **Test** — `qa-engineer` adds/updates tests and runs the suite. *Gate: tests pass and cover the change.*
6. **Ship** — `devops-engineer` handles CI, containers, deploy, and IaC.
   *Gate: green pipeline; rollback path known.*

## Definition of Done

- [ ] Build, lint, and typecheck pass (see `CLAUDE.md` for the commands)
- [ ] Tests cover the change and pass
- [ ] `code-reviewer` found no blocking issues
- [ ] `/security-scan` clean for sensitive changes
- [ ] Lint + typecheck pass; no unhandled promise rejections
- [ ] Access control set explicitly on every collection/global (the default is permissive); migrations reviewed before applying and `push` off for shared databases; types regenerated
- [ ] Accessible markup (labels, keyboard paths, focus)
- [ ] Change summarized with `file:line` references and assumptions flagged

- **Change the process:** reorder phases or add gates — this file is the source of truth for the team.
- **Precedence:** a project-local agent/skill overrides a same-named one in global `~/.claude/`.
- **Regenerate:** `claude-kit --stack …` writes a `.kit-example` copy; diff and merge what you want.
