# apps/web — Astro

The website. It never touches the database; it fetches JSON from Payload's REST API.

| Path | What it is | WordPress equivalent |
| --- | --- | --- |
| `src/pages/index.astro` | Route `/` | `front-page.php` / `archive-service.php` |
| `src/pages/services/[slug].astro` | Route `/services/:slug` | `single-service.php` |
| `src/layouts/Base.astro` | Site shell | `header.php` + `footer.php` |
| `src/components/*.astro` | Reusable bits | `template-parts/` |
| `src/lib/payload.ts` | Typed REST client | `wp_remote_get()` + `WP_Query` |
| `@cms/payload-types` | Types generated by the CMS | — |

Dev server: <http://localhost:4321>
